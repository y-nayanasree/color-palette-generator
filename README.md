# 🎨 Color Palette Generator

A simple and interactive Color Palette Generator built using HTML, CSS, and JavaScript.

## ✨ Features

- Generate five random colors with one click.
- Display HEX codes for every color.
- Click any color card to copy its HEX code.
- Show a confirmation message after copying.
- Responsive design for mobile and desktop screens.
- Automatically generate a palette when the page loads.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```text
color-palette-generator/
├── index.html

├── script.js
└── README.md
```

## 🚀 How to Use

1. Open the Color Palette Generator website.
2. Click **Generate Palette** to create five random colors.
3. Click any color card to copy its HEX code.
4. Use the copied code in your designs.
